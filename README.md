# DeepSeek-Harness-Plugin
## A collection of free, open-source, and ready-to-use agent-developed plugins (UI enhancements, feature extensions, etc.), updated regularly.<br><br>
## 🧩 Plugins

### Each plugin lives in its own directory and installs straight from this repository.<br><br>

| Plugin | What it does | Install |
|---|---|---|
| [dsh-deepseek-theme](dsh-deepseek-theme) | DeepSeek Chat's blue palette and whale brand marks for the DSH Web UI. Ships disabled — enable it in Settings → Plugins. | `github:folks666/DeepSeek-Harness-Plugin#path:/dsh-deepseek-theme` |

### Pinned tag, local path and tarball forms are listed in each plugin's own README.<br><br>
